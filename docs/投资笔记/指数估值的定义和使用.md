# 指数估值的定义和使用



估值的概念



**本文的估值特指基于市盈率、市净率和市销率的价值高低判断**。估值并不是股价price的估算值，而是价值value水平的估算。



先列公式：

市盈率PE = 总市值P/总盈利E

市净率PB = 总市值P/总净资产B

市销率PS ＝总市值P/总销售额S



指数本身原本是没有直接提供估值数据，指数估值数据间接来源于成员股的各项估值的统计结果。

个股估值数据一般来源于Wind, Choice等专业付费数据供应商，然而我穷，是采用“聚宽”网从以上两家数据供应商获取的数据然后用python进行大数据统计。进行过数据对比，跟券商app中显示的没有差异。



通过个股对指数的估值进行统计，方法一般有市值加权法、等权法、中位数法、算术平均数法等等。考虑到不能因为市值较大的较少数股票的估值对指数影响，也就应该是在大家绝大多数便宜的时候才算便宜，大家都贵的时候才贵的原则，我决定采用等权法进行统计。



以指数PE为例，公式为：

等权PE= n/(1/股票1的PE  + 1/股票2的PE + ....+1/股票n的PE)



市盈率，根据它的公式PE=P/E，当价格P为一定值时，如果E越大，说明用同样的钱可能可以获得更多的利润，相反，当E越小，同样的钱可能赢的利润更少。注意“可能”二字，股市当中炒的是一种预期，假设这家公司的盈利能有持续性。



于是我们用PE这样的数据去描述“如果我投了这家公司，依靠这家公司的盈利能力，我可以多少年把我的本金可以回笼，并且新产生的盈利将成为我的纯利润”。答案当然是越短越好。一家公司盈利能力不错，价格又不贵的时候当然是最佳的入场时机。



在指数的PE估值统计过程中，个股的盈利PE不能为0或者是负数，因为1/PE中，分母不能为0；并且当盈利为负数时，我们去谈上一段中的多少年回本的话题就没有意义了，因为是亏损状态，什么时候能盈利都是未知数。



特别是对于周期性的行业，盈利有好坏光景之分，就有可能一些时间里没有盈利，甚至还要消耗资金继续运营而形成暂时亏损现象，毕竟不能直接关门轻易认输啊。



此时，市盈率不再作为可参考的对象时，就需要看看其他的估值。



市净率，总市值除以总净资产的倍数，按照跟市盈率一样的理解套路，就是买单位资产需要的钱越少越好，同样的钱买到的净资产资产越多越好。总结一下，市净率越小越好，小于1时，此时股票市值已经比公司净资产还要便宜，也就是破净。



统计指数市净率时，个股PB跟PE一样，也不能为0和负数。当股票有分红时，分红的部分资金将从净资产当中剔除出去。假设公司存在的时间很久，而且分红足够多的时候，不排除会出现净资产为负数的情况——换个角度理解，曾经投入的净资产通过盈利的方式全部赚回来了，毕竟有真实盈利才会有分红。



市销率，总市值除以总销售额。如果公司忙于扩张，并不能马上实现盈利，而是把一些利润让利给客户，或者盈利用于了增加分店等红利再投资的行为，怎么评估什么时候是买这个指数的好时机呢，当然是同样的市值能实现更多的销售额，市销率越小越好。



不管有没有盈利，销售额是不可能出现负数的，市销率就不会存在负数，相比可能出现负值的市盈率和市净率来说，市销率这数据的作用的确不错，对于指数市销率的统计来说，数据是最完整的。



估值百分位的概念

选取时间窗口为最近5年或最近10年，计算每天的估值数据，把所有估值数据按从小到大排序，以最后一个交易日的估值数据为基准，小于基准的所有数据的个数在所有数据个数中的占比，就是百分位。如果能保证每半个月交易一次的密度，那每半个月取一次估值数据，缩小样本数目，将估值数据曲线钝化，也是可以接受的一种方法，因为不交易的那些日子的估值数据已经不重要了。





估值怎么用？

我们使用估值时，只是指数自己跟自己比估值在历史中的变化情况，而不是同时期的不同种指数间比较。因为不同行业的利润率高低，是否依赖重资产，是否经常有销售额成交等，都是不一样的，不能轻易跨行业比较。



通常情况下，可以根据估值百分位去掌握同一个指数的投资节奏。



按照百分位的数据范围，人为的把百分位分为了以下几个程度进行量化交易：

极度高估(>90%)，高估(80%~90%)，正常偏高(60%~80%)，正常(40%~60%)，正常偏低(20%~40%)，低估(10%~20%)，极度低估(5%~10%)，历史大底（<5%)



基本上估值百分位40%一下就可以开始买进，同一个价值水平，买够指定的仓位就停止，直到更低的价值百分位水平出现，再进一步买进，越跌越买。



在指数价值高估以后，就可以开始卖出了，越涨越卖，卖光为止。

估值数据的局限性

1.指数的成分股纳入规则有变化。

当指数选股规则变化较大时，导致变化前后的成分股行业分布剧烈变化，这个指数实质上变成了另一种指数，同样的估值数据，已经不能说明当下的价值了。



2.正在产生新的历史

我们统计历史情况，但是今天的数据在明天看来就是历史数据，有可能今天产生新低（新高），明天更低（高）。越是提示历史大底越要小心。情绪奔溃或者高涨的时候，趋势的力量是可怕的。



3.指数成立时间太短

指数成立时间过短，即使不够长，没有经过至少一轮牛熊，就不知道它跌起来涨起来的可怕程度，此时估值百分位虽然真实但是不实用。



4.并不能利用估值百分位去投资个股

指数是个群体化的概念，代表的是平均水平，所以指数化的估值是有一定参考意义的，但是个股情况就不一样。哪怕个股经历了几次牛熊，即使现在是极度低估，还是因为其他原因而继续跌妈不认。



比如“华夏幸福”，17元时已经极度低估甚至历史大底了，因为债务过多，回款过慢的原因，继续跌到5块多。如果17元重仓买入，现在呵呵。个股有个股投资的逻辑，我们这不做更多讨论——我坦白，我也不懂。
